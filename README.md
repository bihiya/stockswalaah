# StockWallah

StockWallah is a microservices-based stock portfolio platform built using React, Node.js, Kafka, Redis, and MongoDB Atlas.

## Features

- User Authentication
- Portfolio Management
- Watchlists
- Real Time Notifications
- Corporate News
- AI Sentiment Analysis
- Audit Logging
- Kafka Event Driven Architecture
- Redis Caching

## Tech Stack

### Frontend

- React
- Redux Toolkit
- Material UI

### Backend

- Node.js
- Express.js

### Messaging

- Apache Kafka

### Database

- MongoDB Atlas

### Cache

- Redis

### Authentication

- JWT
- Refresh Tokens

## Services

- API Gateway
- Auth Service
- Portfolio Service
- Notification Service
- Sentiment Service
- Corporate News Service
- Audit Service
